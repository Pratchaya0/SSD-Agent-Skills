AI Foundation

เข้าใจว่า LLM คืออะไร และ Prompt ทำงานยังไง

🧠

LLM คืออะไร?

Large Language Model — โมเดลที่ฝึกบนข้อความปริมาณมหาศาล เรียนรู้รูปแบบภาษาจนสามารถสร้างข้อความที่ "สมเหตุสมผล" ต่อไปได้

🎯

Token คืออะไร?

AI ไม่อ่านทีละตัวอักษร แต่อ่านทีละ "token" ซึ่งอาจเป็นคำ, ส่วนของคำ, หรือเครื่องหมาย — ขีดจำกัดการจำของ AI วัดเป็น tokens

💬

Context Window

ช่วง "หน่วยความจำ" ที่ AI อ่านได้ในครั้งเดียว ยิ่งใส่ context ที่ดี ยิ่งตอบได้ตรงมากขึ้น

🔬 Token Visualizer

ลองพิมพ์ข้อความ แล้วดูว่า AI แบ่งมันเป็น token ยังไง

🏗️ Anatomy ของ Prompt ที่ดี

✗ Prompt ที่ไม่ดี
"ช่วย review code หน่อย"

❌ ไม่มีบริบท ไม่รู้ว่า code อะไร มาตรฐานไหน ต้องการอะไร

✓ Prompt ที่ดี
[บริบท] ฉันเป็น dev SSD ทำงานกับ React/TS
[สิ่งที่ต้องการ] review OrderForm.tsx
[มาตรฐาน] ตาม SSD standard: ใช้ Formik, ห้าม any
[output] รายงาน violations พร้อม line number

✅ ชัดเจน มีบริบท มีเป้าหมาย มีมาตรฐานอ้างอิง
